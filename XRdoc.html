简介

脚本引擎基于 BeanShell，支持 Java 8 语法，不支持注解。脚本目录位于模块数据目录下的 plugin 文件夹中，支持本地创建与从在线脚本库下载。

开发环境说明

脚本运行于 Modern BeanShell 环境（支持 Java 8+）。编写时请遵循以下规范：

  • 属性访问：推荐使用成员符 . 直接访问对象属性（如 msgData.msg），无需调用 Getter 或复杂反射。
  • 方法访问：无需强制类型转换即可自动调用对应签名的方法和字段。
  • 全局作用域：context、classLoader 及所有 API 方法在脚本任意位置（含内部类、Lambda）均可直接调用，无需传递。
  • 语法支持：完整支持 Java 8 特性，包括 Lambda 表达式（->）、流式 API（Stream），此外支持 Kotlin 空安全操作符 ?.（安全调用）与 ?:（Elvis 操作符）以简化空值处理。
  • 线程模型：事件回调默认在 IO 线程 执行。操作 UI 需切换至主线程，内置 toast 已自动处理线程切换。
  • 宿主交互：脚本持有宿主和模块的 ClassLoader，可直接 import 类并使用。

Lambda 表达式支持

理论支持标准 Java Lambda 语法，可用于简化代码或实现各类函数式接口（如 Runnable、Comparator、Consumer 等，以及脚本中自定义的符合单抽象方法的接口）。

基础语法

支持 -> 表达式，可用于单行语句或代码块。

// 示例 1: 启动线程 (Runnable)
new Thread(() -> {
    // 处理逻辑...
    log("线程执行中");
}).start();

// 示例 2: 列表排序 (Comparator)
Collections.sort(list, (a, b) -> a.length() - b.length());

// 示例 3: 结合 Stream 使用
list.stream().filter(s -> s.startsWith("A")).count();

方法引用 (::)

支持通过双冒号 :: 引用现有的 Java 方法：

  • 静态方法：如 Math::max
  • 实例方法：如 System.out::println
  • 类名引用实例方法：如 String::toUpperCase
  • 构造函数：如 ArrayList::new

引用脚本方法 (this::)

可以使用 this 关键字引用当前脚本中定义的方法（包括自定义方法和 API 内置方法），检测比较宽泛，参数数量与目标接口函数匹配即可，尝试调用失败时报错。

// 定义一个脚本方法
public void handleItem(Object item) {
    log("处理: " + item);
}

// 在需要函数式接口的地方引用它
list.forEach(this::handleItem);

// 也可以直接引用 API 提供的内置方法
list.forEach(this::log);

一、消息相关方法

1. sendMsg：发送消息

方法重载 1：sendMsg(String PeerUin, String 内容, int 聊天类型)

  • 聊天类型：1 好友 / 2 群聊 / 100 陌生人
  • 支持格式：
    • 艾特：[atUin=QQ号]（QQ 号为 0 时表示艾特全体）
    • 图片：[pic=图片链接或绝对路径]
  • 可任意组合，将根据形式自动解析

方法重载 2：sendMsg(Object Contact对象, String 内容)

2. sendPic：发送图片

  • 重载 1：sendPic(String PeerUin, String 图片路径, int 聊天类型)
  • 重载 2：sendPic(Object Contact对象, String 图片路径)

3. sendPtt：发送语音

  • 重载 1：sendPtt(String PeerUin, String 语音路径, int 聊天类型)
  • 重载 2：sendPtt(Object Contact对象, String 语音路径)
  • 重载 3：sendPtt(String PeerUin, String 语音路径, int 聊天类型, int durationMs)
  • 重载 4：sendPtt(Object Contact对象, String 语音路径, int durationMs)

durationMs 为毫秒；不传时从 silk 估算，失败回退 1000ms。

4. sendCard：发送 JSON 卡片

  • 重载 1：sendCard(String PeerUin, String JSON字符串, int 聊天类型)
  • 重载 2：sendCard(Object Contact对象, String JSON字符串)

5. sendFile：发送文件

  • 重载 1：sendFile(String PeerUin, String 文件路径, int 聊天类型)
  • 重载 2：sendFile(Object Contact对象, String 文件路径)

6. sendVideo：发送视频

  • 重载 1：sendVideo(String PeerUin, String 视频路径, int 聊天类型)
  • 重载 2：sendVideo(Object Contact对象, String 视频路径)

7. sendReplyMsg：发送引用回复

  • 重载 1：sendReplyMsg(String PeerUin, long 引用消息ID, String 内容, int 聊天类型)
  • 重载 2：sendReplyMsg(Object Contact对象, long 引用消息ID, String 内容)

8. recallMsg：撤回消息

  • 重载 1：recallMsg(int 聊天类型, String PeerUin, long 消息ID)
  • 重载 2：recallMsg(Object Contact对象, long 消息ID)

9. sendPai：拍一拍

sendPai(String 被拍者Uin, String PeerUin, int 聊天类型)

PeerUin：在群里则是群号，私聊则是好友 QQ。

完整示例

一个监听群消息并自动回复的脚本示例：

// 监听群消息，检测关键词后自动回复
public void onMsg(Object msgData) {
    int type = msgData.type;
    if (type != 2) return; // 只处理群聊

    String content = msgData.msg;
    if (content == null || content.isEmpty()) return;

    if (content.contains("你好")) {
        sendMsg(msgData.peerUin, "你好呀，我是自动回复机器人", 2);
        qqToast(2, "已自动回复: " + msgData.peerUin);
    }
}

// 群成员入群欢迎
public void joinGroup(String group, String member) {
    sendMsg(group, "[atUin=" + member + "] 欢迎加入本群~", 2);
    log("welcome", "新成员入群: " + member + " -> " + group);
}

// 卸载时清理
public void unLoadPlugin() {
    log("lifecycle", "脚本已卸载");
}
